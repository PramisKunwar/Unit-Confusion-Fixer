# Unit Confusion Fixer
A Chrome extension that detects physical quantities on any webpage and shows SI unit conversions in retro-styled tooltips. Built for Physics Grade 11/12 students.

## Feature
- Converts km/h → m/s, g → kg, cm → m, and more
- Supports mechanics, electricity & wave units
- Hover any detected quantity for instant conversion
- Toggle ON/OFF from the popup

## Additional features:
- Manual Converter — type any value+unit (e.g. 72 km/h) and hit GO or Enter to get the SI conversion instantly.
- Session History — every conversion (manual) is stored for the current browser session and displayed in a scrollable list with a CLEAR button. History resets when the browser closes.
- Formulas tab with 30+ key formulas from mechanics, thermodynamics, waves, electricity, and modern physics (click to copy)
- Expanded constants with astronomical (solar/earth mass, AU, parsec, ly) and Coulomb constant
- MutationObserver for dynamic content detection
- Scientific e/E notation support (e.g., 1.6e-19)

## Installation 
Install: Unzip → chrome://extensions → Developer mode → Load unpacked
